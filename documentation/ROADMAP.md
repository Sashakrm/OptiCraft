# OptiCraft — дорожная карта

> План и отметки ниже сохранены как рабочая история; наличие пункта без отметки не означает отсутствия частичной реализации. Актуальное устройство описано в [технической документации](TECHNICAL_DOCUMENTATION.md). В частности, враждебные мобы уже реализованы, но полный критерий фазы остаётся для проверки.

Цель: дойти до контентной параллели с Minecraft 1.8, затем — собственное развитие сверху.
Движковая часть (рендер, чанки, генерация, персистентность, свет, day/night) уже готова и
дальше не переделывается ради новых фаз, только расширяется по необходимости.

**Правило одной активной задачи:** внутри фазы работаем над одним подшагом за раз. Отвлекающие
идеи не реализуются на лету — они дописываются в конец этого файла в раздел «Отложено».
Следующая фаза не открывается, пока не закрыт definition of done текущей.

## Фаза 1 — Базовый survival-луп

- [x] 1.1 Голод: второй ресурс рядом с health, тик урона от голода при полном истощении

- [x] 1.3 Инструменты: разное время добычи разными инструментами (кирка/топор/лопата/рука)

- [x] 1.5 Формат рецептов (JSON по аналогии с `blocks.json`) + загрузчик
- [x] 1.6 Крафт 2×2 из инвентаря (без стола) — базовые предметы
- [x] 1.7 UI верстака 3×3 (новый экран в HUD по аналогии с существующим инвентарём)
- [x] 1.8 Наполнение дерева крафта (доски → палки → инструменты и т.д.)
- [x] 1.9 Пассивный моб: позиция, блуждание, коллизия с миром, дроп ресурса при убийстве
- [x] 1.10 Враждебный моб: спавн ночью (уже есть day/night), атака игрока и игроком, дроп
- [ ] 1.11 Звук: базовые эффекты (шаги, удары, добыча) и фоновая музыка

**Definition of done фазы:** можно проголодаться, умереть, возродиться, скрафтить полный набор
базовых инструментов, встретить моба и убить/быть убитым — без ручных правок кода под конкретный
случай.

Технически самая сложная вставка в текущую архитектуру — новая подсистема
`src/world/Redstone.*` с пер-тиковым графом обновлений поверх чанк-хранилища. Планировать
отдельно, не смешивать с геймплейными фазами.

- [ ] 4.1 Провод и распространение сигнала между чанками
- [ ] 4.2 Факел, кнопка, рычаг, нажимная плитка
- [ ] 4.3 Дверь/люк на редстоуне

**Definition of done фазы:** простая схема (рычаг → провод → дверь) работает предсказуемо на
границе чанков.

## Фаза 7 — Абстракция «мир» (без мультиплеера)

Без сетевого трека это не полная архитектурная переделка, а точечное обобщение: переход между
обычным миром/Адом/Краем с загрузкой/выгрузкой соответствующего мира и раздельными сохранениями
на измерение.

- [ ] 7.1 Возможность иметь больше одного набора чанков/сохранения одновременно в памяти на
      время перехода
- [ ] 7.2 Раздельные каталоги сохранений по измерениям (по аналогии с уже существующим
      разделением Classic/Islands)

**Definition of done фазы:** переход между двумя мирами не теряет и не мешает состояние ни
одного из них.

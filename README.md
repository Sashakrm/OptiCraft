# OptiCraft

OptiCraft — учебный C++-проект воксельного игрового движка в духе Minecraft. Проект использует OpenGL, потоковую загрузку чанков, процедурную генерацию мира и GPU-driven рендеринг.

## Текущая версия — 0.10.4

**Добавлено и изменено:** обновлены 39 биомов: океан, мелководье, пляж, равнины, лес, берёзовый лес, тайга, джунгли, саванна, пустыня, каменная пустыня, степь, тундра, ледяные поля, горы, высокие горы, плато, слизовый, солнечный, небесный, подземный, глубокий подземный, затопленный подземный, умеренный дождевой лес, болото, мангровое болото, вишнёвая роща, буковый лес, осиновая роща, луг, редколесье, бэдленды, холодная пустыня, снежная тайга, альпийский луг, холодный океан, тёплый океан, коралловый риф и грибные поля. Исправлено отображение ступенек и полублоков в инвентаре; добавлены деревянные ступеньки и полублоки для 16 пород древесины с рецептами крафта.

## Сборка

```bash
cmake -S . -B cmake-build-debug
cmake --build cmake-build-debug -j 4
```
